# prototypes/ — স্থানান্তরিত (২৭ নভে. ২০২৬)

এই ফোল্ডারের ক্যাননিক্যাল কপিগুলো মাস্টারপ্ল্যান ভাগ ১৪.৪ অনুযায়ী `cosmos/` মনোরিপোতে স্থানান্তরিত হয়েছে:

| আগে | এখন (ক্যাননিক্যাল) |
|---|---|
| `prototypes/explorer-react/` | `cosmos/explorer/` |
| `prototypes/dighonto/` | `cosmos/prototypes/dighonto/` |
